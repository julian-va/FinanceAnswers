# FinanceAnswers

This is a Kotlin Multiplatform project for a financial Q&A application, built with Compose Multiplatform.

## Project Structure

The main logic is located in `composeApp/src/commonMain/kotlin`. This is a KMP project targeting Android and iOS.

## How to Run

- **Android:** Open the project in Android Studio and run the `composeApp` configuration.
- **iOS:** Open `iosApp/iosApp.xcworkspace` in Xcode and run the project.
